# 2048 Game - Exact Classic Clone Specification

## Goal
Build an exact, faithful clone of the original 2048 game (https://play2048.co/ or gabrielecirulli 2048).

## Requirements - Must match classic exactly

### Core Gameplay
- 4x4 grid
- Start with exactly TWO random tiles on empty board
- Each tile is either 2 (90% chance) or 4 (10% chance)
- Moves: Arrow keys (Up, Down, Left, Right). Also support WASD for convenience?
  - Original uses only arrows, but many clones support swipe + arrows
- On move:
  - All tiles slide in direction until they hit edge or another tile
  - Identical tiles that collide MERGE into sum (2+2 -> 4)
  - Merged tiles do NOT merge again in the same move (e.g. 2 2 2 2 -> 4 4  , not 8)
  - After a successful move (board state changed), add exactly ONE new tile (2 or 4)
- Score: sum of the values of all merged tiles added to score each move
- Game WIN: when a 2048 tile is created (show "You win!" but allow continue playing by default, like original)
- Game OVER: when board is full AND no possible moves (no two adjacent tiles have same value in row or column)

### UI - Classic Look & Feel
- Dark gray background (#faf8ef or close)
- The grid container has rounded corners, light beige cells
- Tiles:
  - Empty cells: #cdc1b4 background
  - 2: #eee4da , dark text #776e65
  - 4: #ede0c8 , dark #776e65
  - 8: #f2b179 , white text
  - 16: #f59563 , white
  - 32: #f67c5f , white
  - 64: #f65e3b , white
  - 128+: brighter with special effects, white text, larger values may shrink font
  - Exact font: "Clear Sans", "Helvetica Neue", Arial, sans-serif ; bold
  - Numbers centered in square tiles
  - Tile pop animation on spawn
  - Merge animation (scale up then down)
  - Slide animation (smooth transition)
- Header: "2048" title large left, Score box right with label "SCORE" and big number
- Optional: Best score persisted in localStorage
- Below header or beside: New Game button
- Game messages overlay:
  - "Game over!" with "Try again" button
  - "You win!" with "Keep going" and "Try again"
- Responsive: centered on page, works on mobile (touch swipe support)
- Keyboard only when focused or global

### Technical
- Pure client side: single index.html or index.html + css + js (no external deps except google font if nice)
- No build step required. Open index.html directly works
- Or provide `npm run serve` if using simple setup
- Fully functional with zero config
- Use requestAnimationFrame or CSS transitions for smooth movement
- All game logic in pure JS, separated if possible for testability

### Controls
- Arrow keys: move
- Optionally: swipe gestures (touchstart/move/end) on the board
- New Game button resets
- (Original does not have undo - do NOT add undo unless specified; keep faithful)

### Exact Behavior to Replicate
- Random tile placement only in empty cells
- Correct "can't move" detection
- No tiles added on invalid move (if you press key but no change, nothing happens)
- When merging, the score added is the value of the new merged tile (e.g. merging two 8s adds 16 to score)
- Continue playing after 2048
- Tile values only powers of two

### Files
Create these in /2048/ folder:
- index.html (main app + structure)
- styles.css (exact styling match)
- game.js (core logic + renderer + input handling)
- README.md (how to run: just open index.html in browser)

## Verification Criteria
The game must be playable and match classic 2048:
1. Opens in browser, shows title, score 0, empty grid with 2 initial tiles
2. Arrow keys slide tiles correctly
3. Merging works, score increases correctly, new tile appears only on valid move
4. 4 2 2 2 horizontal left -> becomes 4 4 2 (empty)  note correct merge-once
5. Reach 2048: win banner appears but can continue
6. Fill board with no moves: game over
7. New Game resets everything
8. Touch swipe works on phones/tablets
9. Looks visually very close to original (colors, fonts, layout, tile size ~107px or proportion)

No extra features like "auto play", timers, themes unless classic.
