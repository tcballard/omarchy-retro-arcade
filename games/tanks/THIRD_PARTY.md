# Tanks provenance

The Tanks engine, frontend, AI, synthesized PCM cues and shelf illustration are
original Arcade code and geometry under GPL-3.0-or-later. No third-party game code, graphics,
fonts or sounds have been imported into this game.

Shared cabinet presentation, Omarchy theme loading and storage helpers come from
this repository and retain their existing notices. Dependency licences remain
recorded by the workspace and distributed package.
