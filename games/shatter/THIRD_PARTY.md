# Provenance

Shatter's paddle, bricks, ball, capsules, effects, SVG shelf illustration and all
20 named layouts are original native/vector geometry authored for Omarchy Arcade.
No Arkanoid branding, level data, artwork or recordings are included.

The PCM playback code derives from Arcade's Bubble implementation in this same
repository (GPL-3.0-or-later), with Shatter-specific synthesized cue pitches.
The theme loader and cabinet presentation are existing Arcade components; see
shared/presentation/assets/README.md for the shared cabinet's provenance.
