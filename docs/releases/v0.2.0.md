# Omarchy Arcade v0.2.0

Twelve games in one native Omarchy app, with shared collection navigation,
desktop theme integration and local saves. No account is required for offline play.

## Included

Circuit Pinball, Solitaire, Scram, Invaders, Chess, Stack, Snake, Bubble, Blast,
2048, Shatter and Tanks. The Arch player package includes Stockfish for offline
computer Chess.

Tanks brings solo Easy/Normal AI and local two-player artillery, destructible
hills, wind, three weapons and first-to-two matches. Original sound, recoil,
animated impacts, falling tanks, damage labels and reduced effects complete its
first playable version. Pausing or reopening preserves the match, including
shots in flight and terrain settling.

Circuit Pinball now supports typing and editing saved high-score names, reliable
Ctrl+V paste, UTF-8 limits and persistence across restarts. Thanks to CanadaApollo6
for [the contribution](https://github.com/tcballard/omarchy-retro-arcade/pull/38).

2048 and Shatter join the earlier nine-game collection. Existing game licences,
artwork attribution and save locations are retained. See the per-game Help and
About screens for controls and credits.

## Install and upgrade

Publication is pending. When the v0.2.0 assets are available, download the player
package and SHA256SUMS from the same release. In that directory:

```sh
sha256sum --ignore-missing --check SHA256SUMS
sudo pacman -U ./omarchy-retro-arcade-0.2.0-1-x86_64.pkg.tar.zst
omarchy-retro-arcade --version
```

The version command should report `Omarchy Arcade 0.2.0`. Launch from the desktop
menu, or run `omarchy-retro-arcade --game tanks`. Debug symbols are optional and
are not needed to play. Pacman owns updates; there is no separate self-updater.

Close Arcade before upgrading. Back up the existing save directories described
in [migration notes](../MIGRATION.md); retain the old package if you may downgrade.
Pinball retains settings and records, not an unfinished table.

To downgrade, close Arcade and use `sudo pacman -U /path/to/previous.pkg.tar.zst`.
A package downgrade does not undo newer save schemas. Restore the matching backup
if the older build rejects a save; retain the newer save separately. Do not delete
state directories during uninstall (`sudo pacman -R omarchy-retro-arcade`).

## Verification and known limits

The merged baseline `8d1d74d09bf6a1f5ef2bece9df2be9fdc4bf81d7` passed all three
[CI jobs](https://github.com/tcballard/omarchy-retro-arcade/actions/runs/34886679784):
engine checks, native build/tests and Arch packaging. This includes twelve-game
native switching, pointer layouts and an installed-package save-preservation
check. The upgrade check reinstalls the same package; it does not establish an
old-version-to-v0.2.0 migration matrix.

This candidate also includes #38, merged as
`26ab74c014c490af5112fc2fecd57604627d06d8`. The earlier successful baseline run
predates that merge; its [new main run](https://github.com/tcballard/omarchy-retro-arcade/actions/runs/34894755633)
and the final versioned commit must pass the gates again. Its release bundle records
its own commit, tree, workflow run and artifact checksums. Historical tests are
not evidence for a different versioned binary.

Target: Omarchy 4 / Hyprland. Automated GUI checks use Linux/Xvfb, not a live
Omarchy desktop. Audible output, complete human matches and gameplay balance
still need desktop playtesting. x86_64 is the prepared binary target; aarch64
remains unverified. This is a community app, not an official Omarchy package.

No tag or GitHub release has been published by this preparation change.
