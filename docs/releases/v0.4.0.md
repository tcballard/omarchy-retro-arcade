# It’s all downhill from here

![FreeSki gameplay with fast mode and a creature in pursuit](https://raw.githubusercontent.com/tcballard/omarchy-retro-arcade/7d6e5f42b2e451ea08649eca577675990e58e9d8/games/freeski/assets/shelf.png)

Omarchy Arcade v0.4.0 release candidate. The x86_64 bundle has passed CI; final desktop acceptance and publication remain pending.

FreeSki joins Arcade: fourteen games in one native window, playable offline.

- **Find your feet.** Practice on an authored 1,200-metre slope with carving, braking, ramps and crash recovery.
- **Keep going.** Free Ski offers a seeded endless mountain, optional creature pursuit and separate distance records with pursuit on or off.
- **Race the gates.** Five Slalom courses unlock in order, with local medals and five-second penalties for missed gates.
- **Come back later.** Runs save at checkpoints and when paused or closed, then reopen paused. Records, preferences and course unlocks stay local.

Use A/D or the arrow keys to steer, or move the mouse to choose a heading. Brake with S, Down or the right mouse button on the slope. F toggles fast mode. Ramps launch automatically; Esc pauses and Ctrl+H returns to Arcade. [Full controls and save behaviour](https://github.com/tcballard/omarchy-retro-arcade/blob/v0.4.0/games/freeski/README.md).

This release also separates the host and shared platform code, improves focus-loss input handling, stops Chess/Scram/Invaders audio workers when leaving a game, and keeps normal Pinball shutdown responsive while preserving cleanup and save-lock ordering.

Thanks to [MayberryDT](https://github.com/MayberryDT) for bringing [FreeSki to Arcade](https://github.com/tcballard/omarchy-retro-arcade/pull/42).

FreeSki uses original artwork, courses, sounds and creature design. No proprietary SkiFree assets are bundled. All thirteen existing games and bundled Stockfish remain included.

## Install or upgrade after publication

Download the x86_64 player package and SHA256SUMS from the published v0.4.0 release. Close Arcade and back up your saves before upgrading.

```sh
sha256sum --ignore-missing --check SHA256SUMS
sudo pacman -U ./omarchy-retro-arcade-0.4.0-1-x86_64.pkg.tar.zst
omarchy-retro-arcade --game freeski
```

The executable should report `Omarchy Arcade 0.4.0` with `--version`. Pacman owns updates; there is no app self-updater.

## Saves and rollback

Existing games retain their save locations. FreeSki uses `$XDG_STATE_HOME/omarchy-retro-arcade/freeski.json`, normally `~/.local/state/omarchy-retro-arcade/freeski.json`. Invalid or newer-format saves remain untouched until an explicit archive/reset. Earlier-rule records remain available in Settings; revised runs use separate difficulty records and retain course unlocks.

To downgrade, close Arcade and install the previous package using `sudo pacman -U /path/to/previous.pkg.tar.zst`. Keep both your backup and current saves: a package downgrade does not reverse save migrations. v0.3.0 has no FreeSki and will not resume its runs. Uninstall with `sudo pacman -R omarchy-retro-arcade`; retain state directories to keep progress.
