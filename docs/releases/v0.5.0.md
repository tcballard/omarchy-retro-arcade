# Hold the pass

![Ridgeline: a Last Pass wave against a colour-coded defence](https://raw.githubusercontent.com/tcballard/omarchy-retro-arcade/70b5a45bbdeb52887b74912fef69489687a6e9b5/games/ridgeline/docs/shelf.png)

Omarchy Arcade v0.5.0 release candidate. Publication waits on a CI-verified candidate and final desktop acceptance.

Ridgeline joins Arcade: fifteen games in one native window, playable offline.

- **Build the line.** Cannon, Mortar, Flak and Cryo, each with two upgrades. Every stat change is shown before you spend.
- **Read the road.** Crawlers, fast Scouts, armoured Plated units, slow Haulers and Gliders that only Flak can reach. Each wave's line-up, health and armour are shown before you send it.
- **Take the campaign.** Ten authored maps, each with its own lesson and a separate Hard table. Clear and Perfect medals are recorded per difficulty.
- **Take your time.** Nothing moves until you start a wave. You can build, upgrade and sell while paused, and play at 1× or 2×. Interrupted waves reopen paused, exactly where you left them.

Pick a tower with 1–4 or its card and click open terrace to place it. Arrows and Enter work too. U upgrades, Space sends the next wave, F toggles 2×, Esc cancels placement or pauses, and Ctrl+H returns to Arcade. [Full controls and rules](https://github.com/tcballard/omarchy-retro-arcade/blob/v0.5.0/games/ridgeline/README.md).

Ridgeline uses original maps, waves, artwork and synthesized sound. Canyon Defense and other tower-defence games were design references only; nothing is copied. All fourteen existing games and bundled Stockfish remain included.

## Install or upgrade after publication

Download the x86_64 player package and SHA256SUMS from the published v0.5.0 release. Close Arcade and back up your saves before upgrading.

```sh
sha256sum --ignore-missing --check SHA256SUMS
sudo pacman -U ./omarchy-retro-arcade-0.5.0-1-x86_64.pkg.tar.zst
omarchy-retro-arcade --game ridgeline
```

The executable should report `Omarchy Arcade 0.5.0` with `--version`. Pacman owns updates; there is no app self-updater.

## Saves and rollback

Existing games keep their save locations; no other game's save or settings format changes in this release. Ridgeline saves to `$XDG_STATE_HOME/omarchy-retro-arcade/ridgeline.json`, normally `~/.local/state/omarchy-retro-arcade/ridgeline.json`. Invalid or newer-format saves stay untouched until you explicitly archive them and start fresh.

To downgrade, close Arcade and install the previous package with `sudo pacman -U /path/to/previous.pkg.tar.zst`. v0.4.0 has no Ridgeline and ignores its save file, which stays in place for a later upgrade. Uninstall with `sudo pacman -R omarchy-retro-arcade`, and keep the state directories to keep progress.

## Evidence and remaining checks

Ridgeline's engine is deterministic. A reference strategy wins every map on both difficulties through the production engine. Its winning replays are checked in and verified at 1× and at 2× with uneven frame times.

CI covers workspace formatting, strict Clippy and tests; fifteen-game switching; mouse navigation; Ridgeline keyboard play, pause, save and reopen in dark, light, compact and 200% layouts; and Arch package installation. The package check includes a suspended Ridgeline wave staying byte-identical across a same-package reinstall.

That evidence comes from Xvfb and the Arch container. It does not establish:

- human pacing and difficulty on Omarchy/Wayland;
- a full old-version upgrade matrix;
- aarch64 acceptance.

No leaderboard or multiplayer service is deployed.

The release bundle must include the player package, corresponding source (Arcade, pinned Stockfish source and evaluation network), BUILD.txt and SHA256SUMS. Match BUILD.txt to the final tag commit before publication. This is a community app targeting Omarchy 4 / Hyprland; official package-repository promotion is separate.
